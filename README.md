# 🎓 Student Mark Calculator

A Flask-based web application for calculating student marks, average, percentage, performance, and pass/fail status.

## 🌐 Live Website

 https://student-mark-prediction-f84s.onrender.com

## Features

- Student name input
- Multiple subjects
- Total marks calculation
- Average calculation
- Percentage calculation
- Performance evaluation
- Passed and failed subject count
- Responsive web interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
